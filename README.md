# Fábrica de Cómics — Consola Editorial Privada

Sistema central para crear y administrar cómics y cuentitos vinculados exclusivamente a San Patricio del Chañar.

**Principio:** mucha estructura detrás, máxima sencillez delante.

## Flujo maestro

OBRA → NATURALEZA → FICHA → BIBLIA → ESCENAS → PRODUCCIÓN → QA → PUBLICACIÓN → LECTOR

La consola de producción y el lector público son capas diferentes.

## Naturalezas

- HISTORIA
- MEMORIA
- TERRITORIO
- FICCIÓN
- HISTORIA + FICCIÓN

## Regla

La consola organiza y controla. No reemplaza el criterio editorial, la documentación ni la revisión humana.

## Estado

La primera versión funcional de la consola establece el modelo de trabajo y su navegación. Las futuras capas deben ampliar profundidad sin romper el flujo simple.
