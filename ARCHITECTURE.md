# Fábrica de Cómics — Arquitectura editorial

## Propósito

La Fábrica no es solamente un lector ni un generador de imágenes. Es el sistema central para producir una biblioteca de cómics y cuentitos exclusivamente vinculados a San Patricio del Chañar.

## Cuatro naturalezas narrativas

1. HISTORIA — hechos respaldados por fuentes.
2. MEMORIA — testimonios y recuerdos, identificados como tales.
3. TERRITORIO — inspiración nacida del paisaje, objetos, costumbres y experiencias.
4. FICCIÓN — personajes y acontecimientos inventados.

Una obra puede combinar capas, pero nunca confundirlas.

## Pipeline

ARCHIVO → DOCUMENTACIÓN → CONCEPTO → GUION → BIBLIA VISUAL → MODELOS → STORYBOARD → ILUSTRACIÓN → LETTERING → CONTINUIDAD → QA → PUBLICACIÓN.

## Regla de oro

Muchísima estructura detrás. Máxima sencillez delante.

## Fábrica vs obra

La Fábrica administra la producción.

Cada obra tendrá su propia carpeta/repo cuando llegue a producción, pero compartirá reglas, taxonomías y criterios editoriales con esta Fábrica.

## Datos mínimos por obra

- id
- título
- tipo narrativo
- época
- lugares
- personajes
- fuentes
- nivel de certeza
- público
- formato
- estado de producción
- canon
- continuidad
- arte
- publicación

## Estados

IDEA → INVESTIGACIÓN → CONCEPTO → GUION → PREPRODUCCIÓN → ARTE → INTEGRACIÓN → QA → PUBLICADA → ARCHIVADA.

Nunca saltar directamente de IDEA a PUBLICADA.

## Criterio editorial

Una historia histórica no se inventa para llenar huecos.

Una ficción no se presenta como hecho real.

Un testimonio no se convierte automáticamente en verdad documental.

El territorio puede inspirar sin quedar falsificado.

## Objetivo

Construir, con el tiempo, una biblioteca narrativa de San Patricio del Chañar: diversa en edades, estilos y géneros, pero coherente en identidad territorial.
